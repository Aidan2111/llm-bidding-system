# Code of Conduct

This project expects professional, constructive participation. The goal is to
make the codebase more useful and trustworthy for people building supervised
LLM routing systems.

## Expected Behavior

- Be respectful of different experience levels and operating constraints.
- Keep criticism specific to code, docs, tests, security, or product behavior.
- Assume contributions need review, tests, and revision before merge.
- Redact secrets, customer data, private source, and sensitive prompts.
- Take responsibility for AI-assisted contributions. Review, test, and own the
  content before submitting it.

## Unacceptable Behavior

- Harassment, threats, insults, or sustained disruption.
- Publishing private information without permission.
- Submitting credentials, exploit details, or private task text in public.
- Misrepresenting generated content, test results, security status, or project
  capabilities.

## Enforcement

Maintainers may edit, hide, close, or reject issues, pull requests, comments, or
other contributions that violate this code. Repeated or severe violations may
lead to a ban from the project spaces. For sensitive conduct concerns, contact
the maintainer through a private channel if one is available; otherwise open a
minimal public issue requesting a private channel without naming people or
posting private details.

This policy is informed by common open source practice, including Contributor
Covenant-style expectations and Microsoft-style guidance that code of conduct
and reporting paths should be visible to contributors.
